Tables4U

Software Engineering at WPI, fall 2024. Team project.

Code on GitHub

Tables4U has three kinds of users. Diners search for restaurants that are open on a given date and time, book a table and cancel if they need to. Restaurant owners set up their restaurant, add tables, set their hours, close specific days and see who is booked. An administrator can see every restaurant and pull availability reports.

How it's built

We designed it in UML first. The front end is Next.js, React and Tailwind CSS, deployed on Vercel. The back end is a set of REST APIs, each one an AWS Lambda function behind API Gateway, with the data in a MySQL database on Amazon RDS.
